# Editorial Canvas

https://portx.framer.ai/

Create a premium, highly polished personal portfolio website inspired by the visual language of the Portx Framer template: dark editorial Swiss design, brutalist typography, extreme whitespace, oversized text, monochrome UI, subtle borders, smooth scroll animations, horizontal motion, and sophisticated micro-interactions.

IMPORTANT:
Do NOT create a generic developer portfolio.
Do NOT use colorful gradients, glassmorphism, cards everywhere, excessive rounded corners, stock-dashboard layouts, or conventional SaaS UI.
The website should feel like an award-winning creative studio / designer portfolio from Awwwards, FWA, or CSS Design Awards.

The design should feel:

* Minimal
* Experimental
* Editorial
* Premium
* Artistic
* Brutalist but refined
* Typography-driven
* Extremely clean
* High-end creative agency
* Dark and monochromatic
* Motion-focused

==================================================

1. GLOBAL VISUAL DIRECTION
   ==================================================

Use a nearly-black background (#0A0A0A or similar) throughout the main experience.

Primary text:

* Off-white / white
* High contrast
* Large typography

Secondary text:

* Medium gray
* Low-contrast metadata

Accent:

* Keep the interface almost entirely monochrome.
* If an accent is needed, use it extremely sparingly.

Avoid:

* Purple gradients
* Blue gradients
* Neon effects
* Excessive shadows
* Glassmorphism
* 3D blobs
* Generic startup illustrations
* Excessive cards
* Rounded UI components

The website should look almost like a printed high-fashion editorial magazine translated into an interactive digital experience.

Use thin 1px borders in dark gray for section separators.

Use a strict grid system with generous margins.

Desktop layout:

* Maximum content width around 1400–1600px
* Large horizontal padding
* 12-column grid
* Strong alignment between sections

Mobile layout:

* Preserve the same visual identity
* Reduce typography proportionally
* Maintain generous vertical spacing
* Never allow the desktop design to simply overflow horizontally

==================================================
2. TYPOGRAPHY
=============

Typography is the PRIMARY design element.

Use a modern grotesk / Swiss sans-serif such as:

* Inter
* Helvetica Neue
* Neue Montreal
* Geist
* Arial as fallback

Use multiple weights:

* Regular
* Medium
* Semibold
* Bold

Hero typography should be enormous.

Use:

* Tight letter spacing
* Tight line height
* Occasional uppercase typography
* Strong contrast between giant headlines and tiny metadata

Examples:

HERO:
"NASREDDINE"
"AMRAOUI"

or:

"BUILDING"
"DIGITAL"
"EXPERIENCES."

The main hero title should occupy a significant portion of the viewport.

Some headings should use stretched tracking or spaced-out typography, for example:

U I / U X
D E V E L O P M E N T
M O B I L E / W E B

Use small uppercase labels such as:

//
SELECTED WORK
//
ABOUT
//
EXPERIENCE
//
SERVICES

These labels should be small, understated, and aligned consistently.

==================================================
3. NAVIGATION
=============

Create a minimalist fixed/sticky navigation.

Desktop:

LEFT:
NASREDDINE / AMRAOUI

CENTER or secondary area:
PORTFOLIO

RIGHT:
[CONTACT]

The navigation should be very small compared with the hero.

Use:

* Transparent/dark background
* Minimal borders
* No traditional hamburger on desktop
* Subtle hover animations

The CONTACT button should not look like a conventional rounded button.

Instead, use a minimal bordered rectangular interaction.

On hover:

* Background changes
* Text inverts
* Smooth 300–500ms transition

The navigation should remain visible while scrolling but should subtly transform in size/opacity.

"Mobile & web developer focused on building thoughtful digital products, interfaces and experiences."

Add a small circular or arrow icon indicating scrolling.

The hero should feel almost empty.

Do not fill the hero with cards or illustrations.

==================================================
5. HERO MOTION
==============

Use sophisticated entrance animation.

On page load:

1. Background appears.
2. Small metadata fades/slides upward.
3. Main typography reveals line by line.
4. Secondary text appears.
5. Scroll indicator begins subtle movement.

Animation characteristics:

* 600–1200ms
* Smooth cubic-bezier easing
* No bouncy cartoon animations
* No excessive scaling

Use staggered text reveals.

The animation should feel expensive and deliberate.

==================================================
9. PROJECT INTERACTIONS
=======================

Make portfolio projects highly interactive.

On hover:

* Image slightly scales from 1.00 to 1.03
* Cursor changes
* Project title shifts
* Arrow appears/moves
* Metadata fades or changes

Use a custom circular cursor.

For example:

VIEW
PROJECT

The custom cursor follows the mouse with slight easing.

When hovering over an image:

* Cursor becomes larger
* Background changes
* Text appears

Keep all interactions subtle.

==================================================
10. PORTFOLIO SCROLL EFFECT
===========================

Use smooth scrolling.

Create occasional horizontal scrolling / horizontal project movement inside vertical sections.

The page should feel dynamic without becoming chaotic.

Use:

* Parallax
* Image reveal animations
* Text reveal animations
* Sticky project sections
* Horizontal movement
* Scale transitions
* Opacity transitions

Animations must be performance-friendly.

Do not animate every element.

Motion should communicate hierarchy.

====================

==================================================
23. RESPONSIVE DESIGN
=====================

Desktop:

* 1440px+
* Huge typography
* 12-column grid
* Horizontal project compositions

Tablet:

* 768–1199px
* Reduce typography
* Maintain grid
* Preserve whitespace

Mobile:

* 320–767px
* Single-column layout
* Large but controlled typography
* 20–24px horizontal padding
* No horizontal overflow
* Simplify animations
* Disable custom cursor
* Stack portfolio metadata
* Maintain large visual hierarchy

The mobile version must feel intentionally designed, NOT like a desktop website squeezed into a phone.

==================================================
24. PERFORMANCE
===============

Prioritize:

* Smooth 60fps animations
* Lazy-loaded images
* Optimized image sizes
* Minimal JavaScript
* Avoid unnecessary animation libraries
* Use transform/opacity for animations whenever possible

Animations should not cause layout shifts.

26. IMPORTANT DESIGN RULE
=========================

The website should NOT look like a collection of UI components.

It should look like ONE continuous visual composition.

Every section should transition naturally into the next.

Large typography + whitespace + thin lines + image compositions + subtle motion are the main design language.

The website should feel closer to:

Awwwards-winning creative portfolio
+
Swiss editorial design
+
Brutalist web design
+
Premium digital studio

rather than:

Typical developer portfolio
+
SaaS landing page
+
Bootstrap website.
